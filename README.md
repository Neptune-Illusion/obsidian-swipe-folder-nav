# Swipe Folder Navigation

Swipe Folder Navigation 是一个支持移动端手势与桌面端命令的 Obsidian 笔记导航插件。在移动端笔记页面左右滑动即可切换同文件夹笔记：左滑打开下一篇，右滑打开上一篇。桌面端提供前后文件切换和滚动到笔记末尾的命令，导航会复用当前页面，不会为每次切换创建新的标签页。

## 桌面端命令

桌面端命令面板中新增：

- `Navigate to next file`：打开排序中的下一个 Markdown 文件。
- `Navigate to previous file`：打开排序中的上一个 Markdown 文件。
- `Scroll past end of note`：将编辑器光标移到末行，并滚动到笔记末尾之外。

桌面端导航范围默认为当前文件夹，也可以在插件设置中切换为整个 vault。启用“跟随文件浏览器排序”后，命令会使用 File Explorer 当前的排序方式；移动端手势和原有命令不受该选项影响。

## 安装

1. 在本项目中运行 `npm run build`。
2. 将生成的 `main.js`、`manifest.json`、`styles.css` 复制到 vault 的 `.obsidian/plugins/swipe-folder-nav/` 目录下。
3. 打开 Obsidian 设置 → 第三方插件，在已安装插件中找到 Swipe Folder Navigation 并启用。

在桌面端可到设置 → 快捷键，搜索 `Swipe Folder Navigation`，为三个桌面命令分配快捷键。

## 设置

| 设置项 | 默认值 | 含义 |
| --- | --- | --- |
| 排序方式 | 文件名 | 按文件名、修改时间或创建时间排列同文件夹笔记 |
| 反向排序 | 关闭 | 反转上一篇/下一篇的顺序 |
| 循环切换 | 关闭 | 到达首篇或末篇时跳到另一端 |
| 最小滑动距离 | 80 px | 触发导航所需的最小水平滑动距离 |
| 最大垂直偏移 | 60 px | 允许的垂直位移上限，超过后视为滚动 |
| 切换时提示 | 关闭 | 切换后显示目标笔记名，或在边界显示提示 |
| 桌面端导航范围 | 当前文件夹 | 选择在当前文件夹或整个 vault 中导航 |
| 跟随文件浏览器排序 | 开启 | 桌面端导航使用 File Explorer 当前的排序方式 |

## 已知限制

- 滑动手势只在移动端阅读模式下生效；桌面端请使用命令面板或已配置的快捷键。
- 只导航 Markdown 文件（`.md`），不包含图片等附件。
- 只处理当前文件夹的直接子文件，不递归进入子文件夹。
- 在代码块、表格、宽公式等横向滚动区域内，滑动优先用于滚动该区域；滚到边界后再次滑动才翻页。
- 超出页面宽度的块级公式会自动等比缩小以完整显示；缩放有下限，极端超长的公式仍可横向滚动查看。
